# Aadarsh Digital Health

Build and publish a complete frontend website for Aadarsh Multispeciality Hospital in one pass.

Use the uploaded screenshot only as inspiration, but create a fresh premium UI with deep navy + teal + mint + white colors, modern typography, rounded cards, clean spacing, subtle animations, and professional medical imagery.

Include Home, About Us, Our Lifesavers (Doctors), Departments, Services, Health Packages, Contact, Appointment, plus Gallery dropdown → Photo Gallery / Video Gallery.

Make all navigation, dropdowns, doctor cards, gallery lightbox/video modal, appointment form, mobile menu, buttons, and routing fully functional on the frontend.

Use React + responsive CSS, proper high-quality images, and mobile/tablet/desktop support. No backend/database. Add realistic placeholder hospital/doctor content where needed.

Important: Make the website production-ready and publish-ready. Do not leave unfinished sections, broken links, placeholder layouts, or TODOs. Prioritize a polished working result over unnecessary features.
